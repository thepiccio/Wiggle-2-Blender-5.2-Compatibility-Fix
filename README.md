A compatibility-fixed version of Wiggle 2 for Blender 5.2.

This version fixes issues caused by changes in the Blender Python API for Blender 5.x, including:

Bake Wiggle fix: Resolves an error that caused the Bake Wiggle operation to fail.

Bone Selection fix: Restores the ability to correctly select bones by clicking on them in the newer Blender version.

📦 What is included?
The ready-to-use .zip file of the addon, fully tested with Blender 5.2.1.

Immediate access to updates if further compatibility issues arise.

📥 How to install & use:
After purchase, download the .zip file.

Open Blender, go to Edit > Preferences > Add-ons.

Click on Install in the top right, select the downloaded .zip file, and enable the addon.
